# 경영현황 통합 대시보드 — 사용 가이드

경영실적·재무 이력·KPI 대시보드 운영 가이드. "이럴 땐 이렇게" 순서로 정리함.
DB 없이 PC 한 대에서 Flask(백엔드) + Vite(화면)로 돌림 — 이 PC가 꺼지면 대시보드도 꺼짐.

---

## 1. 처음 세팅 (한 번만)

```bash
pip install -r requirements.txt
cd frontend && npm install
```
1. `.env.example`을 `.env`로 복사
2. `.env`에 계정·키 채움
   - `ADMIN_ACCOUNTS="사번:비밀번호:이름"` — 관리자(조회 + 관리자 기능)
   - `USER_ACCOUNTS="사번:비밀번호,…"` — 일반 회원(조회만). 명단 엑셀이 있으면 `python scripts/fill_user_accounts.py 명단.xlsx --apply`
   - `H_CHAT_API_KEY` 등 — AI 인사이트·실적 자동 반영 요약용
3. 아래 "2. 켜기"로 실행

---

## 2. 켜기 / 끄기

```bash
python dashboard_manager.py --start   # 켜기 (dashboard_start.bat 더블클릭도 같음)
python dashboard_manager.py --stop    # 끄기
```
- 내 PC: `http://localhost:5188`
- 다른 사람: `http://<이 PC IP>:5188` (예: `http://10.206.32.222:5188`)
- 로그인 필요 — 사번·비밀번호

## 3. 이럴 땐 이렇게

### 새 실적 파일(사업계획 통합관리 파일)이 왔을 때
1. 파일을 `data/`에 넣음 (또는 ⚙ > 관리자 기능 창에 끌어다 놓기)
2. 끝 — 5초 안에 서버가 알아서 읽음
   - 열이 밀려도 자동으로 맞추고, 계산식 검증 통과해야 반영
   - 실패하면 **직전 파일 그대로** 보이고 이유는 관리자 기능 창에 → 확인 후 "다시 시도"
- 파일명 날짜(`_yymmdd_`)가 가장 최신인 파일, 그 안에서 최신 시트(같은 달이면 집계 > 추정)를 고름
- 지난 파일은 `data/경영실적 히스토리/`로 옮겨 두면 됨

### PPT 보고서가 수정됐을 때 (재무·KPI)
⚙ > 관리자 기능 > PPT 추출
- **증분** — 바뀐 파일만. 보통 이걸로
- **선택** — 고른 파일만 다시(그 파일의 기존 행 지우고 새로). PPT에서 지운 행·바꾼 코드까지 반영하려면 이걸로
- **초기화** — 전부 다시. 오래 걸림
- 끝나면 화면 자동 갱신. 실패한 파일은 "추출 현황"에서 확인 → "실패 N개 다시 추출"

### 누가 "PPT 업데이트 요청"을 눌렀을 때 (헤더 노란 "!")
1. 노란 "!" → 요청 목록(원본 바뀜 여부 표시)
2. "N개 선택 추출로 열기" → 그대로 실행
3. 다시 추출되면 목록에서 저절로 빠짐

### 헤더에 빨간 "!"(데이터 이상)가 떴을 때
- 코드 충돌·재무↔KPI 코드 불일치·완료보고 이상 — 대부분 PPT 오입력
- 담당자가 PPT 고친 뒤 "수정 완료" 누르고 → 관리자가 그 파일 다시 추출하면 사라짐

### 공개 범위(달성률·파일 바로가기 등)를 바꾸고 싶을 때
⚙ > 관리자 기능 > 공개 범위 — 바꾸면 모든 사람 화면에 바로 적용

### 계정을 추가·변경했을 때
`.env` 수정 → **Flask 재시작**(`--stop` 후 `--start`)

### 코드(.py)를 고쳤을 때
**Flask 재시작** 필요. `/api/*/reload`는 엑셀만 다시 읽고 코드는 안 바뀜. 프론트(.tsx)는 저장하면 바로 반영

## 4. 문제가 생겼을 때

| 증상 | 확인할 것 |
|------|----------|
| 재무 데이터가 0건 | `data/재무관점 필수 데이터 추출.xlsx`를 Excel로 열어서 AIP 암호화됐는지 → 재추출로 덮어쓰기 |
| PPT 고쳤는데 안 바뀜 | 저장 시각이 추출보다 뒤인지 / 추출 현황에서 그 파일이 "열기 실패"인지 / 지운 행이면 "선택" 방식으로 |
| 추출 현황 "원본 폴더에 접근할 수 없습니다" | 탐색기로 `\\10.206.32.3\기술교육팀` 다시 로그인(자격 증명 저장) |
| 다른 PC에서 화면은 뜨는데 API 오류 | 이 PC Flask가 죽었거나 옛 코드로 떠 있음 → 재시작 |
| 코드 고쳤는데 화면이 그대로 | 개발 서버가 변경을 못 알아챔 → 파일 다시 저장 또는 재시작 |
| `git pull`이 untracked 파일 때문에 멈춤 | `data/` 아래 엑셀이 추적 대상이었던 것 — `.gitignore` 최신 받고 해당 로컬 파일 잠깐 옮긴 뒤 pull |

## 5. 하면 안 되는 것

- ⚠️ **NAS(`\\10.206.32.3\기술교육팀`) 파일 수정·삭제 절대 금지** — 읽기 전용. 추출 결과는 항상 로컬 `data/`
- NAS PPT를 이 PC PowerPoint로 직접 열지 말 것 — DRM이 원본을 다시 암호화한 적 있음
- 결과 엑셀(`data/*.xlsx`)을 Excel로 열고 저장하지 말 것 — AIP 레이블 붙으면 못 읽음
- `.env`·비밀번호·`data/` 커밋 금지
- 실적 자동 반영 검증 기준(95%)을 느슨하게 바꾸지 말 것

## 6. 숫자 규칙 (코드 손댈 때만)

- 계산은 백엔드, 프론트는 단위 변환·표시만
- 실적 = 천원(억 = ÷100,000), 재무 = 원
- 실적 누계는 1~기준월만 다시 더함 (원본 "N월 실적" 열은 1~12월 전체라 그대로 쓰면 부풀려짐)
- "매출 − 원가" = 매출이익. 경상손익 = 매출이익 − 인건비 − 공통원가 − 관리비
- 손익률 평균 = Σ경상손익 ÷ Σ매출 (단순평균 금지)
- KPI는 같은 프로젝트면 가장 진행된 단계 1건만

바꿀 땐 원본 엑셀로 직접 재계산해 대조하고 `docs/session-log.md`에 근거 남길 것. 전체 규칙은 `CLAUDE.md`.
