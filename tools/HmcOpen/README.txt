대시보드 파일 열기 도구
======================

무엇인가요
  대시보드의 "파일 바로가기(↗)"·"폴더 바로가기"를 눌렀을 때, 대시보드를 켜 둔 PC가 아니라
  지금 쓰고 있는 내 PC에서 NAS의 원본 PPT(또는 그 폴더)가 열리게 해 주는 작은 도구입니다.

설치 (PC마다 한 번, 관리자 권한 필요 없음)
  1) 압축을 풉니다. (압축을 푼 폴더 안의 파일을 그대로 두세요)
  2) install.bat 을 더블클릭합니다.
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
  3) "설치가 끝났습니다"가 나오면 완료. 대시보드가 자동으로 열리고 바로가기 버튼이 나타납니다.
  4) 처음 파일을 열 때 브라우저가 "열도록 허용할까요?"라고 물으면 "항상 허용"을 선택하세요.

안 열릴 때
  - NAS(\\10.206.32.3\기술교육팀) 폴더에 내 계정으로 접근할 수 있어야 합니다. 탐색기에서 먼저 열어 보세요.
  - 설치 후에도 "동작 확인 실패"가 나오면 회사 보안 정책이 스크립트 실행을 막는 경우입니다 — IT 담당자에게 문의.

보안
  - 이 도구는 지정된 NAS 보고서 폴더 아래의 PPT 파일만 엽니다(다른 경로·실행 파일은 거절).
  - 현재 사용자 설정(HKCU)에만 등록하며, 제거는 uninstall.bat.

설치 위치: %LOCALAPPDATA%\HmcOpen   |   등록: HKCU\Software\Classes\hmcopen
IT 팀이 일괄 배포할 때는 install.bat 을 사용자 로그온 스크립트로 실행하면 됩니다(url.txt가 없으면 대시보드를 자동으로 열지 않음).
