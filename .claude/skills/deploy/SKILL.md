# /deploy — 커밋 & GitHub Push 스킬

## 언제 사용하나
작업이 완료된 후 변경사항을 GitHub에 올릴 때. `/deploy` 라고 입력하면 실행된다.

## 실행 순서

1. **변경사항 확인**
   ```bash
   git status
   git diff --stat
   ```

2. **스테이징 & 커밋**
   - 변경된 파일을 확인 후 관련 파일만 `git add`
   - 커밋 메시지는 한국어로 작업 내용 요약
   - 형식: `git commit -m "작업 요약 (세부 내용)"`

3. **Push**
   ```bash
   git push origin main
   ```

4. **CLAUDE.md 세션 기록 업데이트**
   - `## 세션 진행 기록` 섹션에 오늘 날짜 + 완료 작업 추가
   - 발생한 문제가 있으면 `## 알려진 문제 코드` 섹션에도 기록

5. **완료 보고**
   - Push된 커밋 해시와 변경 파일 목록을 사용자에게 알림

## 주의사항
- `.env` 파일, API 키, 개인정보가 포함된 파일은 절대 커밋하지 않는다
- `EXCEL_PATH` 같은 로컬 전용 경로가 코드에 남아있으면 사용자에게 알린다
- 충돌이 있으면 강제 push 하지 말고 사용자에게 먼저 확인한다
