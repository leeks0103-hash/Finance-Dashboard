## 목적
주제와 핵심 내용을 입력하면 python-pptx로 .pptx 파일을 자동 생성합니다.

## 절차
1. 발표 주제, 대상 청중, 발표 시간 확인 (불명확하면 먼저 질문)
2. `template.md` 참고해 목차 및 슬라이드 구성 설계 후 사용자 확인
3. python-pptx 스크립트(`scripts/generate.py`) 실행해 .pptx 생성
4. 생성된 파일 경로를 사용자에게 안내

## 핵심 루프
슬라이드 1장씩 → 내용 검토 → 수정 → 다음 슬라이드 → 완성본 커밋

## 자체 검증 체크리스트
- [ ] 슬라이드 수가 발표 시간에 적절한가? (1장 = 약 1~2분)
- [ ] 각 슬라이드에 핵심 메시지가 1개씩 있는가?
- [ ] 제목 슬라이드 / 목차 / 마무리 슬라이드가 포함됐는가?
- [ ] 시각 자료(차트·표·이미지) 지시사항이 포함됐는가?
- [ ] .pptx 파일이 정상 생성됐는가?

## 주의사항
- python-pptx 미설치 시: `pip install python-pptx` 안내
- 재무 대시보드 데이터(`/api/summary`, `/api/insights`)를 슬라이드에 활용할 수 있음
- 생성된 .pptx는 `output/` 폴더에 저장
