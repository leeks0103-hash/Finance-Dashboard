# PPT 슬라이드 템플릿

## 기본 구성 (발표 10분 기준)

| 슬라이드 | 제목 | 내용 요소 |
|----------|------|-----------|
| 1 | 표지 | 제목, 부제, 발표자, 날짜 |
| 2 | 목차 | 주요 섹션 나열 |
| 3~N-1 | 본문 | 섹션별 핵심 메시지 + 근거 |
| N | 마무리 | 요약, 시사점, Q&A |

## 슬라이드 작성 원칙
- 슬라이드당 텍스트 5줄 이내
- 핵심 수치는 크게 강조
- 차트·표 활용 시 `[차트: 종류 및 데이터]` 형식으로 지시사항 기재

## 재무 대시보드 연계 템플릿

### 재무 현황 보고용 슬라이드 구성
1. 표지 — 보고 기간, 작성 부서
2. 전체 요약 — 매출·지출·이익 KPI 카드
3. 파트별 실적 — 막대 차트
4. 이익율 TOP 5 프로젝트 — 표
5. 리스크 프로젝트 — 표 + 원인 분석
6. 원가 구성 — 파이 차트 (직접원가 / 인건비 / 공통원가)
7. 시사점 및 개선 방향
